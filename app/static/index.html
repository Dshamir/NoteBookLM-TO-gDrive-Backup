      Create your Google Drive OAuth client

      1. Open Google Cloud Console → create a project (e.g. nlm2drive).
      2. Enable the Google Drive API.
      3. Audience: if you use a Google Workspace account, choose Make internal (best: no verification, no expiry). Otherwise press Publish app → In production. Leaving it in Testing causes “Access blocked: … has not completed the Google verification process” (Error 403) unless you are a listed test user, and tokens expire after 7 days.
      4. Clients → Create client → type Desktop app → Download JSON.
      5. Upload that file with the credentials.json button, then press Connect. On the “Google hasn't verified this app” screen choose Advanced → Go to nlm2drive (it is your own app).
